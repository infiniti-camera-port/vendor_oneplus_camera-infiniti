# vendor_oneplus_camera-infiniti

OnePlus 15 (infiniti) per-device camera source contract. `camera-infiniti.mk`
inherits `camera-sm8850-common.mk`, while `proprietary-files.txt` and
`extract-files.py` drive the paired generated repo:
`proprietary/vendor/oneplus/camera-infiniti`.

- Build path: `vendor/oneplus/camera-infiniti`
